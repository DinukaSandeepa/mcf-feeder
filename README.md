# Movie Series News Bot (RSS to Telegram)

A Python-based automation bot designed to be deployed as a **Render Web Service**. It fetches movie series news from RSS feeds, saves them to **MongoDB** to prevent duplicates, and posts them to a **Private Telegram Channel** with images and descriptions.

## 🚀 Features
- **RSS to Telegram:** Automatically parses feeds from major entertainment news sites.
- **MongoDB Integration:** Stores sent URLs to ensure no duplicate posts.
- **Rich Media Posts:** Sends a photo (extracted from the feed) + Title + Short Description + URL.
- **Bot Commands:** Add/Remove RSS feeds directly via Telegram commands.
- **Render Deployment:** Includes a Flask health-check server and a keep-alive mechanism to prevent Render's free tier from sleeping.

## 🛠 Tech Stack
- **Language:** Python 3.10+
- **Database:** MongoDB (Atlas)
- **Libraries:** `python-telegram-bot`, `feedparser`, `pymongo`, `flask`, `beautifulsoup4`

## 📋 Prerequisites
1. **Telegram Bot Token:** Create one via [@BotFather](https://t.me/BotFather).
2. **Channel ID:** Add the bot as an admin to your private channel and get the ID (e.g., `-100xxxxxxx`).
3. **MongoDB URI:** Get your connection string from [MongoDB Atlas](https://www.mongodb.com/cloud/atlas).

## 🔧 Deployment on Render

1. **Create a New Web Service:** Connect your GitHub repo.
2. **Environment Variables:**
   - `BOT_TOKEN`: Your Telegram Bot Token.
   - `CHANNEL_ID`: Your Private Channel ID.
   - `MONGO_URI`: Your MongoDB Connection String.
   - `APP_URL`: The URL Render gives you (e.g., `https://my-bot.onrender.com`).
3. **Build Command:** `pip install -r requirements.txt`
4. **Start Command:** `python main.py`

## 🤖 Bot Commands
- `/start` - Check if the bot is alive.
- `/addfeed <url>` - Add a new RSS feed to the database.
- `/listfeeds` - View all active RSS feeds.
- `/removefeed <url>` - Remove a feed.
